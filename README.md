# Distribution Curve Tool

## Overview
A modern, dark-themed interactive tool to visualize distribution curves and calculate cutoffs based on target percentages.

## How to Deploy
Since this project is a single self-contained HTML file, it is incredibly easy to deploy.

### Option 1: Netlify Drop (Recommended)
1.  Open [Netlify Drop](https://app.netlify.com/drop).
2.  Drag the `index.html` file (or the folder containing it) onto the page.
3.  Your site will be online instantly!

### Option 2: GitHub Pages
1.  Upload `index.html` to a GitHub repository.
2.  Go to **Settings** > **Pages**.
3.  Select the `main` branch as the source.
4.  Save.

## Local Usage
Simply double-click `index.html` to run it in your browser. No server required.
